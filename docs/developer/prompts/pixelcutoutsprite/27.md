# P27 — Integrierte Studio-Workflows abnehmen und dokumentieren

**Status:** Abgeschlossen; Gate am 6. September 2026 bestanden
**Abhängigkeiten:** P23–P26 mit dokumentierten Gates
**Integrationsplan:** `docs/developer/plans/prompt-studio-integration.md`

## Auftrag an den Coding-Agenten

Lies vor Änderungen den MASTERPROMPT, den lebenden ExecPlan, den vollständigen Integrationsplan
und alle Nachweise P23–P26. Prüfe die gesamte Integration über öffentliche Produktionspfade;
Dateiexistenz oder isolierte Mock-Oberflächen sind kein Abschlussbeleg.

Vervollständige Frontendtests für Header, Studio-Wechsel, erhaltenen Cutout-Kontext,
Mutations-/Dirty-Guards und Prompt-Draft-Lebenszyklus. Portiere und adaptiere alle relevanten
PixelForgeStudio-Tests für Prompt Engine, Wizard, Profile, Storage, Navigation und Recovery.

Ergänze Playwright-Szenarien für identische Studiobuttonmaße, grünen Generatorakzent, aktive,
inaktive und fokussierte Zustände, Prompt-Vollbreite, genau einen Header, internes Scrollen und
fehlende CSS-Auswirkungen auf Cutout-Editoren. Der vollständige E2E-Weg umfasst Entwurf,
Kategorie, Wizard, Ausgabe, nativen Neustart, Draft-/Profilwiederherstellung, Markdown-/JSON-Export,
gültige Übergabe in eine schreibbare Area und die Rückkehr in den unveränderten Cutout-Kontext.
Prüfe zusätzlich die Fälle ohne Vault und mit Read-only-Vault.

Vervollständige Rust-Tests für gültige/ungültige Prompt-Daten, atomare Speicherung,
unterbrochenes Schreiben, unzulässige Pfade, schreibgeschützte Ziele, beschädigte Importpakete und
Commandregistrierung. Führe die verfügbaren zentralen Prüfungen aus:

```bash
python tools/control.py test --suite frontend
python tools/control.py tauri test --cargo
python tools/control.py tauri run --foreground
python tools/control.py tauri build --target linux --bundles deb
python tools/control.py tauri smoke --target linux
```

Wenn ein Host oder Display einen nativen Lauf verhindert, dokumentiere den konkreten Blocker und
behaupte keinen PASS. Prüfe den Generator ausdrücklich offline.

Aktualisiere mindestens `README.md`, `START_HERE.md`, `RELEASE-NOTES.md`,
`docs/guides/prompt-generator.md` und
`docs/developer/prompt-generator-architecture.md`. Beschreibe Studio-Wechsel, App-Datenablage,
Profilimport, neuen Assetentwurf, Recovery, native Exporte, Cutout-Übergabe und Read-only-Grenzen.
Dokumentiere Quellrevisionen und Lizenzhinweise der übernommenen Dateien.

## Gate dieser Phase

- Frontend-Typecheck, Lint, Format, Tests und Produktionsbuild bestehen.
- Rust-Tests bestehen.
- Die native App startet; beide Studios und der vollständige Prompt-Workflow sind bedienbar.
- Der Generator funktioniert offline und behält Profile/Drafts über Neustart.
- Keine Prompt-Styles verändern Cutout-Editoren oder erzeugen einen zweiten Header.
- Bestehende Vaults bleiben ohne ausdrückliche Übergabe unverändert.
- Handoff ist in gültigem Kontext erfolgreich und in fehlendem/read-only Kontext sicher gesperrt.
- Die genannten Nutzer-, Architektur-, Release- und Einstiegstexte entsprechen dem realen Stand.
- Der ExecPlan enthält genaue Evidenz, verbleibende Plattformgrenzen und einen ehrlichen Abschluss.

## Erwartetes Ergebnis

Eine belegte, dokumentierte PixelPromptStudio-Integration mit vollständigem Offline-Workflow und
ohne Regression der abgeschlossenen Cutout-Basis.

**Vorgeschlagener Commit:** `✅ Verify integrated studio workflows`

Setze P27 und die gesamte Erweiterungsserie nur bei belegtem Gate auf abgeschlossen. Veröffentliche
nichts und pushe keine Änderungen ohne gesonderten Auftrag.

## Abschlussnachweis

Das Gate ist bestanden. Die Frontend-Suite umfasst 149 Dateien und 771 Vitest-Tests; fünf
Playwright-Szenarien prüfen Layout, Navigation, PixelForge-V2-Import, Wizard, Reload, Exporte und
die Handoff-Zustände ohne Vault, read-only und schreibbar. Rust-Tests belegen native Persistenz,
Recovery, Import/Export, Pfadgrenzen, Handoff und Commandregistrierung.

Der reale Tauri/WebKitGTK-Lauf sowie das neu gebaute Linux-DEB wurden bei 1440 × 900 sichtbar
bedient. Ein nativ gespeicherter Draft blieb über einen vollständigen Prozessneustart erhalten;
derselbe Ablauf bestand mit auf `127.0.0.1:9` umgeleiteten externen Proxywegen. Der native Lauf
deckte außerdem eine WebKit-unverträgliche zyklische Chunkteilung auf, die vor Abschluss beseitigt
und im endgültigen DEB erneut geprüft wurde. Genaue Befehle, Messwerte, SHA-256 und verbleibende
Plattformgrenzen stehen in der
[P27-Integrationsabnahme](../../acceptance/prompt-studio-integration.md) und im ExecPlan.
